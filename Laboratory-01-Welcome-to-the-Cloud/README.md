Mission Overview
The mission is a cloud computing activity designed to introduce students to a cloud-based Linux environment using KillerCoda. The activity focuses on basic Linux commands, system information gathering, file management, and documenting the completed tasks in a GitHub repository.
Objectives
Access and use a cloud-based Linux environment.
Gather basic system information using Linux commands.
Practice basic Linux file and directory management.
Organize activity files and screenshots.
Document the completed activities using Markdown.
Store and manage the outputs in a GitHub repository.
Activities Performed
Accessed the Linux environment through KillerCoda.
Used Linux commands to check system and user information.
Navigated through directories using the terminal.
Created directories and files for the activity.
Viewed and documented command results.
Organized screenshots and activity files.
Uploaded and committed the completed files to GitHub.
Linux Commands Used
pwd – Displays the current working directory.
whoami – Displays the current user.
hostname – Displays the hostname of the system.
ls – Lists files and directories.
cd – Changes the current directory.
mkdir – Creates a new directory.
touch – Creates a new file.
cat – Displays the contents of a file.
Skills Learned
Basic Linux command-line operations.
Linux file and directory management.
Navigating and working with a cloud-based Linux environment.
Gathering system information using terminal commands.
Organizing and documenting technical activities.
Using GitHub for version control and project documentation.
