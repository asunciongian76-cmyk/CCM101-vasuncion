MISION OVERVIEW

The mission/activity was completed using Killercoda, an online platform that provides a virtual Linux environment for hands-on practice. The main goal of the mission was to become familiar with the Linux command line and learn how to navigate and manage files and directories using basic Linux commands.

OBEJECTIVES

Learn how to access and use a Linux terminal. Practice basic Linux commands. Navigate through directories using the command line. Create and manage files and folders. Display and check information in the Linux environment. Improve confidence in using the Linux terminal.

ACTIVITIES PERFORMED

During the activity, I accessed the Linux environment through Killercoda and practiced different commands in the terminal. I first checked my current directory and identified the user and hostname of the system. I then explored the files and directories using the ls command and navigated between directories using cd.

I also created a new directory using mkdir and created a file using touch. After that, I used cat to display the contents of a file. These activities helped me understand how Linux handles files and directories through the command line.

LINUX COMMANDS USED

pwd – Displays the current working directory. whoami – Shows the current logged-in user. hostname – Displays the name of the computer or system. ls – Lists files and directories. cd – Changes the current directory. mkdir – Creates a new directory. touch – Creates a new empty file. cat – Displays the contents of a file.

SKILLS LEARNED

Basic Linux command-line navigation. Creating and managing files and directories. Using the terminal to interact with a Linux system. Understanding basic Linux commands and their functions. Improving problem-solving and troubleshooting skills. Gaining practical experience with Linux through Killercoda.
